# Inventory Valuation Dashboard

## Project Overview
Developed during a data analytics internship at a manufacturing firm, this project involved building advanced Excel dashboards to track, value, and visualize inventory. The tool bridged the gap between raw data and executive-level decision-making.

## Data Wrangling & Architecture
*   **Data Sanitization & Editing:** To comply with data privacy and confidentiality standards, the raw enterprise dataset extracted from the IQMS system was intentionally edited. Proprietary identifiers were scrubbed, and underlying numerical values were altered or scaled across the 7-year historical dataset to protect corporate interests while maintaining realistic statistical distributions for portfolio demonstration.
*   **Data Cleaning:** Extracted raw, unstructured data spanning a **7-year historical dataset**. Conducted extensive data cleaning, handled missing values, and restructured the layout to ensure accurate calculations.
*   **Tools Used:** Microsoft Excel (Advanced formulas, Power Query, conditional formatting, dynamic sparklines).
*   **Key Metrics Tracked:** 
    *   Finished goods inventory valuation
    *   Uncommitted share percentages
    *   Cross-plant distribution comparisons

## Key Dashboard Features
*   **Multi-Plant Visibility:** Filterable views allowing stakeholders to toggle between months.
*   **Historical Trend Analysis:** Leveraged 7 years of past data to give leadership long-term context on inventory build-up and sales velocity.
*   **Automated Formatting:** Utilized conditional formatting and sparklines to create an intuitive, clean visual hierarchy for non-technical users.

## Business Impact
The final dashboard eliminated manual tracking bottlenecks, providing leadership with instant visibility into inventory valuation and enabling more proactive inventory management across plant locations.
